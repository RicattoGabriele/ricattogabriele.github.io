## Struttura Standard (4 Blocchi Obbligatori)

Ogni cover letter in questo archivio rispetta rigorosamente una struttura modulare in 4 sezioni, pensata per massimizzare l'impatto tecnico ed eliminare i cliché dei testi generici:

```
┌─────────────────────────────────────────────────────────────┐
│ 1. MITTENTE & SALUTO (Header & Parametric Greeting)         │
│    Dati di contatto, link al portfolio, "Dear [Team] at..." │
├─────────────────────────────────────────────────────────────┤
│ 2. INTRO (The Hook / Impact Pitch)                          │
│    Attacco diretto, zero convenevoli, aggancio a una sfida  │
│    tecnica o a un traguardo ingegneristico dell'azienda.    │
├─────────────────────────────────────────────────────────────┤
│ 3. SVILUPPO (Deep Dive, Portfolio Highlights & Challenges)  │
│    Dettaglio tecnico di un progetto (H2-EDGE, aerospike,    │
│    CFD, additive), la sfida affrontata e come è stata vinta.│
├─────────────────────────────────────────────────────────────┤
│ 4. CONCLUSIONE & MOTIVAZIONI (Call to Action & Culture)     │
│    Perché questo team, cosa porto al tavolo, disponibilità. │
└─────────────────────────────────────────────────────────────┘
```
